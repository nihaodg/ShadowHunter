# 挖矿木马应急响应

## 事件特征（分诊依据）

- CPU/内存异常高占用，但 `ps`/`top` 有时查不到（进程隐藏/文件已删）
- `netstat` 发现外连矿池 IP（如 137.184.244.76、pool.usa-138.com）
- 安全设备告警「挖矿行为」、攻击 IP/目的 IP 明确
- 进程名高频：xmrig、yayaya、矿工程序
- 多台服务器同时告警（内网横向扩散）

## 排查要点

1. **进程与占用**：`top -c`、`ps aux`、`ps -ef --forest`；`ps` 查不到时看 `netstat -antlp` 的外联 IP。
2. **外联矿池 IP**：`netstat` 里 ESTABLISHED 到陌生公网 IP/矿池端口。矿池 IP 常见：137.184.244.76、159.223.250.170、206.189.250.2、172.104.170.240 等。
3. **定位不到 PID 的处理**：挖矿文件被删后进程仍在外联，`lsof`/`LD_PRELOAD` 都定位不到 PID → 用**防火墙封禁矿池 IP** 兜底。
4. **入口点**：90% 是弱口令 SSH 爆破 + 内网横向。查 `auth.log`/`secure` 的 Failed password 和 Accepted 记录。
5. **提权风险**：sudo 版本（CVE-2021-3156 覆盖版本如 1.8.23）、内核版本、sudoers 配置。
6. **历史痕迹**：`history` 里搜 yayaya、xmrig、挖矿工具关键词；查用户是否有弱口令被入侵（如 liff 用户）。

## 典型攻击路径

```
弱口令入口（花生壳/SSH 对外暴露弱口令）
  → SSH 爆破成功登录入口机
  → 上传 haiduc（ssh爆破工具）+ masscan（端口扫描）
  → 内网横向 SSH 爆破（1300+ IP）
  → 成功登录多台弱口令服务器
  → 植入挖矿木马（root 权限执行）
```

## 处置建议

1. 隔离挖矿主机（断网/EDR 隔离），**先留存样本**（挖矿程序 MD5）
2. 杀进程（`kill -9 <PID>`）、删挖矿文件、清计划任务/启动项
3. 防火墙封禁矿池 IP（主机 + 边界设备双向封禁）
4. 改弱口令、删无用账号（如 inspur 弱口令 123456a!）
5. 升级 sudo/内核，堵提权漏洞
6. 部署 EDR、全盘查杀、留存病毒样本

## 报告要点

- 事件概述写清：告警来源、首次告警时间、涉及网段
- 事件分析按主机列排查结果，重点讲「定位不到 PID 的原因」和「入口点判定依据」
- 总结给攻击路径：入口 → 爆破工具 → 横向 → 多台失陷
- 建议对应根因：弱口令、对外暴露服务、无终端防护

## 真实案例速记

- **国家基因组科学数据中心**：入口点花生壳弱口令 → SSH 爆破横向 → 7 台服务器失陷挖矿。矿池 IP 137.184.244.76 定位不到 PID（文件已删），建议防火墙封禁。
- **北京师范大学**：对外暴露 SSH（7712 端口）+ inspur 弱口令 123456a! → 爆破工具横向 → 16 台主机同弱口令。挖矿进程 bpf 等 kill 后恢复。
- **中信网络**：火绒扫出 36 个恶意文件，微步云沙箱发现挖矿 URL pool.usa-138.com。
