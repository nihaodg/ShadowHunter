# 钓鱼邮件 / 社工应急响应

## 事件特征（分诊依据）

- 员工收到可疑邮件（带钓鱼链接/附件），已点击/运行
- 客服/管理员接到攻击者电话，被远程指导下载运行文件
- 邮件附件运行后终端被控（回连 C2）
- 员工在联络群报告收到钓鱼邮件

## 排查要点

### 邮件侧分析

1. **邮件头分析**：发件人、收件人、发件 IP、SPF/DKIM。
2. **钓鱼链接分析**：
   - whois 查域名注册时间（近期注册 = 黑产抢注）
   - 解析 IP + 端口开放情况 + 微步情报
   - 访问链接看跳转链（多级跳转到肉鸡/仿冒页面）
3. **附件样本分析**：
   - MD5/SHA256、沙箱运行
   - 加壳/打包方式（NSIS/Go 免杀）
   - 签名信息（合法厂商签名但被二次利用，如山东固信受控端）
   - 释放行为、回连 IP、持久化方式（计划任务/启动项/Defender 排除项/注册表）

### 受害终端排查

1. **浏览器记录**：下载记录、历史记录定位恶意文件来源（163 邮箱下载木马）。
2. **杀软日志**：火绒/360 查杀告警，定位恶意文件和解压文件。
3. **黑客工具痕迹**：fscan 扫描日志、浏览器密码/cookie 导出记录（攻击者收集敏感信息）。
4. **权限维持**：异常计划任务（分离免杀加载 shellcode）、启动项。

### 社工特征（区别于纯技术钓鱼）

- 攻击者**打电话**远程指导运行木马文件
- 客服人员被诱导从邮箱下载并解压执行
- 攻击者获取终端后利用浏览器保存密码登录 web 系统

## 典型攻击路径

```
钓鱼邮件（含恶意附件/链接）
  → 员工/客服点击运行木马（或接电话被指导运行）
  → 终端被控（CobaltStrike/哥斯拉/远控）
  → 窃取浏览器密码、敏感文件（fscan 收集）
  → 利用保存密码登录业务系统（客服登记系统等）
  → 上传 webshell → 内网横向
```

## 处置建议

1. 断网隔离被控终端，留证样本
2. 删恶意文件、启动项、计划任务
3. 杀软全盘查杀，顽固则重装
4. 修改所有可能泄露的账号密码（浏览器保存的密码全部改）
5. 部署钓鱼邮件防护设备、邮件网关
6. 安全意识培训：不点未知附件/链接、不接可疑电话指导操作、不用浏览器保存密码

## 报告要点

- 事件分析分「邮件分析」+「样本分析」+「终端排查」+「业务系统排查」
- 样本分析要细到：打包方式、签名、释放行为、C2 地址、持久化手段（可贴反编译/powershell 片段）
- IOC 单独列出（恶意 URL、IP、样本哈希、手机号）
- 总结给完整攻击链（社工 → 终端 → 密码窃取 → web 系统 → 横向）

## 真实案例速记

- **钓鱼邮件（安恒）**：邮件链接 hotwoolce.cc → 跳转 icgbl.org → 下载「小小助手.exe」。样本为 shellcode loader，回连 103.233.8.100:14992，签名山东固信（合法远控二次利用），写注册表 IpDates_info，加 Defender 排除项，拷贝到 Common Files，PowerShell 计划任务自启动。
- **国开证券**：邮件附件「最新岗位调整通知.exe」Go 免杀，运行释放 gkzq.exe（CobaltStrike），在 C:\Users\Public\Music 发现 wx.exe（fscan 伪装）。二次被控（杀软清理不彻底，还有自启/注入）。
- **教育部客服终端**：客服被电话指导下载运行恶意文件 → fscan 收集密码 → 浏览器保存密码登录客服登记系统 → 上传哥斯拉 webshell（加密流量无法解密）。
