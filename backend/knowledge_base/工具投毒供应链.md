# 工具投毒 / 供应链应急响应

## 事件特征（分诊依据）

- 从非官方渠道/伪造官网下载的工具（Clash、MobaXterm、破解版、绿色版）
- 运行后主机被远控、回连 C2
- 攻击者伪造工具网站投放木马、通过通讯工具发送
- 合法厂商签名被二次利用（远控软件改造）

## 排查要点

1. **下载溯源**：浏览器下载记录，对比**官方下载地址 vs 实际下载地址**（如 MobaXterm 官网 mobaxterm.mobatek.net vs 实际 edvdfh.cn）。
2. **样本分析**：
   - 签名信息（合法厂商签名但被二次利用，如山东固信受控端）
   - 释放行为、回连 C2 地址、持久化方式
   - 威胁情报平台查样本关联
3. **受害链路追踪**：
   - 运维人员电脑被控 → 电脑存密码本 → 攻击者登录 vcenter → 控制服务器
   - 个人终端被控 → 加群二次传播（冒充身份发木马）
4. **进程与端口**：远控工具特征端口（vshell 8084）、可疑进程名（JuZwkASs.exe）。
5. **历史命令删除**：攻击者登录服务器后删 history（rm -rf .bash_history），增加排查难度。

## 典型攻击路径

```
伪造官网/非官方渠道下载工具（含后门）
  → 运行后远控木马（vshell/银狐/Gh0st/CobaltStrike）
  → 回连 C2
  → 窃取密码本 / 登录 vcenter / 加群二次传播
  → 控制服务器（删 history 隐藏痕迹）
```

## 处置建议

1. 隔离被控终端 + 封禁 C2 IP
2. 删恶意文件、远控进程
3. 全盘查杀、重装系统
4. 改所有相关密码（密码本泄露的服务器全部改）
5. 安全意识：官网下载、用前查杀、本地不存明文密码本
6. 堡垒机访问、vcenter 双因子认证

## 报告要点

- 事件分析：下载溯源（官方 vs 实际地址对比）、样本分析、受害链路
- 总结：定性「伪造官网下载捆绑后门工具」+「本地存密码本导致事件扩大」
- 建议对应根因：非官方下载、敏感文件本地明文存储

## 真实案例速记

- **中国人民大学工具投毒**：运维老师下载伪造官网 MobaXterm.zip（edvdfh.cn），vshell 远控（端口 8084），回连 107.148.62.100。电脑存服务器密码本 → 攻击者登录 vcenter → 控制 10.21.x.x 多台服务器，history 被删。
- **北京工业大学（关联）**：Clash-X64.zip 仿冒安装包 → 银狐木马 → 回连 75.2.88.106。
- **钓鱼邮件（关联）**：山东固信受控端二次改造，签名合法但植入后门。
