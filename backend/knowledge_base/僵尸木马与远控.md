# 僵尸木马 / 远控应急响应

## 事件特征（分诊依据）

- 主机持续回连 C2/恶意域名（如 sx.hacksx.top）
- 安全设备告警远控（Gh0st/银狐/CobaltStrike/vshell/远控工具）
- 进程名异常：active_desktop_launcher_x64.exe、gkzq.exe、wx.exe、JuZwkASs.exe 等
- 个人终端被远程操控（加微信群、冒充身份二次传播）
- 威胁情报印证恶意 IP/样本

## 排查要点

1. **网络连接定位进程**：`netstat -ano` + `tasklist` 找外联 C2 的 PID 和进程名。
2. **进程对应文件**：`wmic process get executablepath` 定位文件路径；判断是否系统常规路径。
3. **样本检测**：提取样本 → VirusTotal/微步查杀 → 情报查询 C2 关联样本。
4. **溯源下载途径**：查浏览器下载记录（仿冒安装包如 Clash-X64.zip、MobaXterm.zip）、历史记录。
5. **误报排查（重要）**：Gh0st 告警但主机排查无异常时，核对：
   - MAC 物理地址与告警数据包是否一致（不一致 = 告警主机不是真源）
   - hosts 改 127.0.0.1 后是否仍告警
   - 是否个人终端被控（无法上机排查的终端）
6. **权限维持排查**：计划任务（伪装系统名如 Explorer\setup）、启动项、Defender 排除项、注册表写入。

## 典型攻击路径

```
用户从非官方渠道下载仿冒软件（Clash/MobaXterm/破解版）
  → 运行后释放远控木马（银狐/Gh0st/vshell/CobaltStrike）
  → 回连 C2
  → 远程操控（加群二次传播 / 窃取密码本 / 登录 vcenter / 横向）
```

## 处置建议

1. 隔离受害主机 + 封禁 C2 IP/域名（双向封禁）
2. 删恶意文件、进程、启动项、计划任务
3. 全盘查杀（安全模式查顽固程序）
4. 顽固/深度受控 → 备份后重装系统
5. 禁止非授权程序在 ProgramData/Temp 运行（应用控制）
6. 安全意识：官网下载、不点未知程序、不在本地存明文密码本
7. 个人终端部署 EDR

## 报告要点

- 事件概述写清：通报来源、C2 地址、回连时间、传输数据量
- 事件分析重点：进程定位、样本检测、入侵途径溯源（下载记录 + 情报印证）
- 总结给「一人失陷、多人感染」链式攻击风险提示
- 建议对应根因：仿冒软件、安全意识、无终端防护

## 真实案例速记

- **北京工业大学**：银狐木马回连 75.2.88.106:6006，传输 9.18MB。进程 active_desktop_launcher_x64.exe（PID 14512）。溯源：下载 Clash-X64.zip 仿冒安装包运行。处置：隔离 + 删文件/启动项/计划任务 + 封禁 IP/域名 + 重装。
- **昆仑数智**：Gh0st 远控告警，排查大数据平台服务器**无异常**（MAC 不一致、hosts 改后仍告警），疑点指向个人终端 10.232.228.204。恶意域名 sx.hacksx.top 历史解析发现 NPS 服务。定性：个人终端误下捆绑木马/被社工。
- **中国人民大学工具投毒**：运维老师下载伪造官网 MobaXterm.zip（edvdfh.cn），运行后 vshell 远控（端口 8084），进程 JuZwkASs.exe，回连 107.148.62.100。老师电脑存服务器密码本 → 攻击者登录 vcenter → 控制多台服务器。
