# 勒索病毒应急响应

## 事件特征（分诊依据）

- 文件被加密、后缀异常统一（.Elbie / .xxx 等），桌面/关键目录大量中招
- 出现勒索信（README/说明文档，含赎金要求）
- 系统异常卡顿、进程异常
- 同网段多台主机告警或担心被感染

## 排查要点

1. **确认家族**：根据文件后缀/勒索信判定家族。如 `.Elbie` = phobos 家族（主要通过 RDP 入侵）。
2. **入口点判定**：查 Windows 安全日志 RDP 登录记录。
   - 关键手法：**RDP 登录成功时间与文件加密时间相差不到 1 分钟 → 入口点是 RDP**。
   - 用 LogParser 筛 EventID=4624（LogonType=10 为 RDP）。
   - 查 TerminalServices-LocalSessionManager-Operational 日志定位远程登录 IP。
3. **删除日志痕迹**：中勒索前的 RDP 登录失败（爆破）日志**查不到**，但中勒索后失败日志还在 → 攻击者删除了入侵前日志。
4. **加密进程**：定位加密进程 → 进程对应文件位置（如 `C:\PerfLogs\`）。
5. **横向排查**：查同网段其他主机是否也有 RDP 爆破/登录成功记录，确认影响范围。
6. **白名单绕过**：RDP 设了白名单 IP 登录，推测为白名单 IP 机器失陷后作为跳板（日志被删无法确定）。

## 典型攻击路径

```
RDP 白名单 IP 机器失陷（或直接 RDP 爆破）
  → 远程桌面登录目标机
  → 投入勒索病毒文件
  → 执行加密（文件后缀统一，最后修改时间一致）
  → 删入侵前登录日志
```

## 处置建议

1. **立即断网 + 关机/物理隔离**（防止继续加密和扩散），留证
2. **不付赎金**（付费不一定解密）
3. 同网段 RDP 密码复用的主机立即改强口令
4. 数据恢复：历史快照恢复；无重要数据则重装系统
5. 通知白名单登录 IP 相关人员装杀软自查
6. 堵入口：RDP 关闭/限制、强口令、关高危端口（3389/445/139）、禁 Guest 账号

## 报告要点

- 事件概述写清：中勒索时间、文件后缀、家族判定
- 事件分析重点：**入口点判定依据**（RDP 登录时间 vs 加密时间）、**日志被删证据**
- 总结给影响范围（当前仅一台还是多台）
- 建议对应根因：无全流量/日志审计设备（3 天才发现）、无 WAF、无 EDR、弱口令

## 真实案例速记

- **银河期货**：桌面文件全部 `.Elbie`（phobos 家族），最后修改时间 2023.5.13 16:48:06。RDP 登录成功 16:47:56，相差不到 1 分钟 → 入口点 RDP。中勒索前爆破日志被删，白名单 IP 失陷无法定位，判定影响范围仅当前一台。
- **北京大学国际医院**：WannaCry 通过永恒之蓝（MS17-010）内网横向扩散，无人工参与，是蠕虫型。处置：断网 + 打补丁 + 关 SMB 端口（135/137/139/445）+ 装 EDR。
