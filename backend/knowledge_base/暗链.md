# 暗链（黑帽 SEO / 爬虫分流）应急响应

## 事件特征（分诊依据）

- 用**爬虫 UA**（BaiduSpider/Sogou/360Spider）访问特定路径时显示博彩/色情/不良内容
- 普通用户/浏览器访问同一路径却正常或 404（完美隐藏）
- 域名后加特定路径（如 `/CN/tyq/xxx.shtml`）出现不良内容
- 搜索引擎快照里抓到大量指向异常路径的链接

## 排查要点

1. **复现条件**：确认必须「特定路径 + 爬虫 UA」才触发。换普通 UA 访问是正常报错页 → 典型的暗链分流。
2. **中间件配置排查**：
   - nginx 配置文件（是否被改、是否新增 location/rewrite）
   - Tomcat `server.xml`、`context.xml`（是否被注入 Valve）
   - 是否有新增文件夹（如 tyq 目录）
3. **可疑文件排查**：
   - nginx 目录下 result.txt、nginx.exe、moyv.bin 等（shellcode 加载器 + CobaltStrike 木马）
   - 被篡改的 jar（如 tomcat-common.jar 反编译看有没有恶意 Valve）
   - 全盘搜索可疑 jar/隐藏可执行文件（D盾扫描）
4. **文件时间篡改**：查 powershell 历史执行记录，攻击者用命令修改文件时间（改 server.xml、jar 时间伪装成老文件）。
5. **暗链核心逻辑（以 Tomcat Valve 为例）**：
   - 识别爬虫 UA（BaiduSpider/Sogou/Yisou/Haosou/360Spider）
   - 路径匹配关键词（如 tyq）→ 反向代理到恶意站点（博彩站）
   - 路径不含关键词但 UA 是百度爬虫 → 在 `</body>` 前注入隐藏暗链
   - 搜狗爬虫 → 301 重定向到另一域名
   - 普通用户 → 正常业务逻辑（返回 404，完美隐藏）

## 典型攻击路径

```
攻击者获取服务器权限（历史入侵/CobaltStrike）
  → 上传 tomcat-common.jar（含恶意 Valve）+ shellcode 加载器
  → 篡改 context.xml 挂载 Valve，篡改文件时间伪装
  → 爬虫访问特定路径 → 反代到博彩站（黑帽SEO）
  → 普通用户无感知
```

## 处置建议

1. 注释/移除 context.xml 中的恶意 Valve 配置
2. 删除恶意 jar（含 com.tomcat.CommonValves 的 tomcat-common.jar）、shellcode 加载器、CobaltStrike 木马
3. 全盘搜索清除其他可疑 jar 和隐藏可执行文件
4. 升级应用及依赖 jar，修复已知漏洞
5. 重置所有账户密码（系统/数据库/Tomcat Manager/web 后台）
6. **重装系统**（攻击者已具备文件篡改、植入 CobaltStrike 能力，无法确保无隐藏后门）
7. 排查横向移动：密码复用、RDP/SMB/WinRM 端口开放情况

## 报告要点

- 事件分析要讲清**触发条件**（爬虫 UA + 特定路径）和**暗链分流机制**（可贴反编译的 Valve 逻辑）
- 说明「普通用户看不到」的隐蔽性
- 总结给攻击路径 + 恶意文件清单（路径 + MD5 + 类型）
- 建议对应根因：历史入侵未清、文件篡改、需重装

## 真实案例速记

- **人民大学社会建设暗链**：访问 `/CN/tyq/xxx.shtml` + 爬虫 UA 显示博彩内容。攻击者用 powershell 篡改 tomcat 文件时间，上传 tomcat-common.jar（com.tomcat.CommonValves，matchPath="tyq"，反代到 site.baidusogousites.vip 等博彩站）。nginx 目录发现 nginx.exe + moyv.bin（shellcode 加载器 + CobaltStrike）。处置：注释恶意 Valve + 删恶意文件 + 建议重装。
